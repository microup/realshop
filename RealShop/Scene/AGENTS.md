# AGENTS.md — RealShop/Scene/

## Что здесь

`SceneUiController.cs` — единственный файл. Вызывается каждый кадр из `OnUpdate` (когда мод включён). Работает только с деревом объектов сцены через `GameObject.Find`/`transform.Find`:

- снимает блокировки ремонта (`RemoveBlocks`, объекты `Repair_Parts_2/3`);
- разблокирует junkyard на карте (`MapDestinationButton (5)` — константа имени в точке входа);
- включает верстак/большой стол в `EngineRoom`;
- скрывает магазин (`MapDestinationButton (6)`) и доп. аукцион (`AuctionsButton`) по флагам конфига `IsEnableShop`/`IsEnableAdditionalAuction`;
- фильтрует старые машины/бренды в `ShopCarWindow`/`ShopMenu` (бренд-фильтр по `ListCarNames`).

## Правила этого уровня

- Имена объектов игры — магические строки; менять можно только сверяясь с живой сценой (помощь: `Inspect.UnityObject`). Новые имена кнопок выносить в `internal const` рядом с `JunkyardMapDestinationButtonName` в точке входа.
- `GameObject.Find` каждый кадр — уже предельная нагрузка; не добавлять новых `Find` без крайней необходимости и не вложенять обходы дерева глубже существующих.
- Все действия зависят от флагов `Config` (`IsEnableShop`, `IsEnableBrandFilter`, ...) — новое поведение UI тоже привязывать к флагу, а не включать безусловно.
- Метод `Update` завершается `return` после ветки `ShopCarWindow` — порядок веток значим, перестановку проверять в игре.

## Чего не делать

- Не кэшировать найденные GameObject'ы между сценами без `null`-проверки (после перезагрузки сцены они уничтожены).
- Не трогать видимость объектов, когда `_modIsEnable == false` — это обеспечивает ранний выход в `OnUpdate`.
